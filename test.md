# Gemini-Shield

Gemini-Shield is an AI-powered DevSecOps pipeline that integrates Gemini 2.0 Flash into CI/CD workflows for smarter Infrastructure as Code (IaC) security analysis.

## Features
- AI-based vulnerability detection and remediation suggestions
- Custom dashboard for risk analysis and fix recommendations
- Real-time monitoring with Prometheus and Grafana
- Asynchronous scanning for faster pipeline execution
- Combined validation using Checkov and LLM intelligence
